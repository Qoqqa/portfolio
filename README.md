# RJ Colarina — Portfolio

An animated portfolio built with Astro and TypeScript, deployed to GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Astro, usually http://localhost:4321/portfolio/.

## Customize

Edit `src/pages/index.astro` to update your bio, projects, skills, experience, email, and social links. Replace the placeholder project and experience content before sharing the site.

## Deploy

The GitHub Actions workflow in `.github/workflows/deploy.yml` builds and deploys the site on every push to `main`. In the repository settings, open **Pages** and set **Source** to **GitHub Actions** once.

Live URL: https://qoqqa.github.io/portfolio/
